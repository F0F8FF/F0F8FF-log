화면 아래쪽을 돌아다니는 AI 펫입니다. 말을 걸면 할 일을 추가하고, 집중 타이머를 걸고, 일정과 퇴근 시간을 알려줍니다.

- 저장소: [F0F8FF/pet-ai](https://github.com/F0F8FF/pet-ai)
- 스택: Electron 33 · React 18 · TypeScript 5 · Google Gemini / Ollama · Python(kiwipiepy)

## 기능

- **내 캐릭터 넣기** — ChatGPT Pets로 만든 스프라이트 시트를 넣으면 그대로 걷고, 뛰고, 손을 흔듭니다
- **반응** — 커서를 따라 고개를 돌리고, 문지르면 쓰다듬기, 오래 두면 졸기. 우클릭 메뉴와 더블클릭 말 걸기
- **AI 채팅** — Google Gemini 또는 로컬 Ollama 중 선택. 키가 없어도 자주 쓰는 질문은 앱이 직접 답합니다
- **할 일** — "오늘 꼭"과 "나중에"로 나누고, 아침에 어제 남은 일을 오늘도 할지 묻습니다
- **포모도로** — 집중하는 동안 머리 위에 남은 시간을 띄우고, 하루 집중 시간을 잔디로 보여줍니다
- **캘린더** — 구글 캘린더 ICS 주소를 연결하면 2주 일정을 보여주고 N분 전에 알려줍니다
- **근무 시간 인사** — 출근·점심·퇴근 10분 전에 하루 한 번씩 인사
- **날씨 · 휴식 알림 · TTS · 트레이 상주**

## 클라우드와 로컬 LLM을 모두 지원한 이유

데스크톱 앱은 사용자 환경이 제각각입니다. API 키를 넣기 싫은 사람도 있고, 오프라인에서 쓰고 싶은 사람도 있습니다.
그래서 LLM 계층을 프로바이더로 추상화해서, Gemini(클라우드)와 Ollama(로컬)를 갈아끼울 수 있게 했습니다.

```env
LLM_PROVIDER=gemini   # 또는 ollama
GEMINI_MODEL=gemini-2.5-flash
```

처음에는 `VITE_` 접두사를 붙였는데, electron-vite는 `VITE_`로 시작하는 값을 렌더러 번들에 그대로 박아 넣습니다.
앱을 배포하면 API 키가 평문으로 같이 나가는 구조였습니다. 지금은 메인 프로세스만 키를 읽고,
렌더러는 "키가 설정됐는지" 여부만 받습니다. 배포한 앱에서는 설정 화면에 키를 넣으면 macOS 키체인(`safeStorage`)으로 암호화해 저장합니다.

## 그림은 아무거나, 줄 수는 앱이 센다

ChatGPT Pets 시트는 가로 8칸이지만 줄 수는 캐릭터마다 다릅니다. 사용자에게 몇 줄인지 묻는 대신,
투명 여백을 훑어 줄 경계를 찾고 칸마다 그림이 있는지 세서 동작에 자동으로 연결합니다.
걷기는 이동 거리만큼 프레임을 넘겨 발이 미끄러지지 않게 하고, 시선은 커서 방향을 8방향으로 나눠 시트의 둘러보기 칸 16개를 모두 씁니다.
가져온 그림은 저장소에 넣지 않고 사용자 컴퓨터에만 저장합니다.

## 일정은 OAuth 대신 ICS로

구글 캘린더 API를 쓰면 OAuth 앱 등록과 토큰 관리가 따라옵니다. 펫은 일정을 읽기만 하면 되니,
캘린더마다 있는 "비공개 iCal 주소" 하나로 충분했습니다. 대신 반복 일정(매주·격주·매월, 횟수·종료일, 예외 날짜, 단건 수정)과
시간대 변환은 직접 파싱합니다. 이 주소는 아는 사람 누구나 일정을 볼 수 있는 값이라 API 키와 똑같이 암호화하고, 화면 쪽에는 캘린더 이름만 넘깁니다.

## 위치는 추측하지 않는다

예전에는 IP로 위치를 추측해 날씨를 보여줬습니다. 묻지도 않고 외부 서비스에 IP를 보내는 셈이라,
지금은 설정에서 지역을 직접 고르게 바꿨습니다. 고르기 전에는 날씨를 아예 요청하지 않습니다.

## 한국어 NLP는 Python으로

감정 분석·키워드 추출·기분 리포트는 한국어 형태소 분석이 필요해서
`kiwipiepy` 기반 Python NLP 엔진을 별도 프로세스로 붙였습니다.
JS 생태계에서 한국어 형태소 분석기를 찾기보다, 검증된 Python 라이브러리를 프로세스로 분리해 호출하는 쪽이 안정적이었습니다.

Node.js 18+ 와 (NLP 기능을 쓸 경우) Python 3.9+ 가 필요합니다.
